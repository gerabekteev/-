## Задание — кратко (TL;DR)

**Что сдать на семинар:**
1. **Концепция автоматизации** деятельности организации на основе **экосистемы продуктов 1С** (по кейсу своего варианта).
2. **BPMN-модель бизнес-процессов «Как должно быть»** — Диаграмма взаимодействия:
   - **Пулы** = структурные подразделения организации;
   - **Дорожки** = ролевые функции внутри подразделения.

**ВАЖНО (критерий оценки):** концепция и бизнес-процесс должны быть направлены в том числе на **решение проблем организации, обозначенных в кейсе**.

**Мой вариант — №2: ООО «Проммаш»** (продажа и сервисное обслуживание промышленных аккумуляторов; проблемы — при оформлении командировок сотрудников). Подробности и разбор → [02_Вариант_2_Проммаш.md](02_Вариант_2_Проммаш.md).
